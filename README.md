# exr2hdr
A simple application written in C++ that converts .exr files to .hdr files

## Requirements

* [OpenEXR](https://openexr.com/en/latest/install.html)

# Getting Started

1. Clone using `git clone https://github.com/VergilSparda114514/exr2hdr.git`
2. Run CMake to build the project
3. It is recommended to add the binary to your system's PATH variable
4. Run `exr2hdr [input] [output]` to convert EXR files to HDR files
